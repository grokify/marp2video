# v0.9.0

**Release Date:** 2026-07-27

Adds **local avatar rendering** via LivePortrait + JoyVASA — fully offline
talking-head video generation on Apple Silicon.

## Highlights

- **Local avatar provider:** `--provider liveportrait-joyvasa` for avatar
  commands — no cloud API, no API key required
- **End-to-end offline demo:** `examples/local-avatar/` showing the complete
  pipeline (F5-TTS → local avatar → Whisper → composite)

## Added

- `--provider liveportrait-joyvasa` support in `vac avatar generate`,
  `vac avatar list-avatars`, and `vac slides video --avatar-provider`
- `localProviders` map to skip API key validation for local providers
- `examples/local-avatar/` with 6-slide presentation and detailed README

## Usage

```bash
# Start the local servers (see examples/local-avatar/README.md)

# Generate avatar video locally
vac avatar generate \
  --provider liveportrait-joyvasa \
  --avatar-id example \
  --audio narration.wav \
  --output presenter.mp4

# Or use in the slides video pipeline
vac slides video \
  --input slides.md \
  --tts-provider f5tts-mlx \
  --avatar-provider liveportrait-joyvasa \
  --avatar-id example \
  --output video.mp4
```

## Dependencies

- Upgraded `omniavatar` to v0.3.0 (local render provider)
- Upgraded `omniavatar-core` to v0.4.0 (local render infrastructure)
